# ESP-Hi 机器狗集群管理系统 V1.0

这是一个用于管理和控制ESP-Hi机器狗集群的本地Web应用系统，支持多设备同时连接、运动控制、预设动作执行、舵机校准和动作序列编排等功能。

## 快速启动备选方案

若在执行 `run.bat` 文件时出现错误（如Python环境配置问题、pip依赖安装失败等），且用户不想手动解决这些环境问题，可以直接进入项目的 `dist` 目录运行后端可执行程序（.exe文件）。

**注意**：此exe文件会由开发者随项目开发进度定期更新，用户无需自行重新构建或编译。

## 功能特点

### 1. 设备管理

- 自动发现、记录与删除设备
- 一键选择、连接/断开（支持多设备同时连接控制）

### 2. 运动控制

- **虚拟摇杆**：只在鼠标释放瞬间发送方向，避免频繁指令
- **WASD 键盘**：可长按连续运动，支持自定义"指令下发延迟"

### 3. 预设动作

- 12 种内置动作，前端配有形象的 emoji，点击即可执行一遍
- 预设动作循环：任选其一并设置延迟后自动循环执行同一个动作

### 4. 舵机校准

- 仅允许单台设备进入校准模式，期间锁定其它操作
- 提供"应急清理"按钮：设备意外关机时（无法正常退出舵机校准）强制退出校准并清理状态
- 精准±1° 微调，实时生效

### 5. 动作序列编排

- 可选 12 种预设动作 + 4 种移动方向
- 支持设指令延迟
- 最多支持 10 个动作的编排，编排过程中可随时删除某一动作或清除全部
- 可以只执行一次编排，也可以循环（设置循环间隔）
- 一键开始/停止循环

### 6. 界面与提示

- 顶部实时显示：服务器连接状态、已记录设备数、当前连接设备数
- 右上角 emoji 快捷切换主题🌈 默认深色 | 🧁 马卡龙浅色
- 所有操作均带友好提示，已多轮测试，欢迎反馈新 Bug

## 系统架构

### 后端

- 使用 Flask 框架构建的 Web 服务器
- 采用 Socket.IO 实现实时通信
- 模块化设计：设备管理、扫描服务、校准服务

### 前端

- 基于 HTML5、CSS3 和 JavaScript 开发
- 使用 Socket.IO 客户端进行实时通信
- 响应式设计，支持多种浏览器

## 快速开始

### 环境要求

- Python 3.6 或更高版本
- 安装依赖：Flask、Flask-CORS、Flask-SocketIO 等

### 安装步骤

1. 克隆或下载项目到本地
2. 安装 Python 依赖：

   ```bash
   cd backend
   pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
   ```
3. 运行系统：

   - 双击运行 `run.bat`
   - 或在命令行中执行：
     ```bash
     python backend/app.py
     ```
4. 访问系统：

   - 打开浏览器，访问 http://localhost:5000

## 使用说明

### 1. 扫描设备

- 点击"开始扫描"按钮，系统将自动扫描局域网内的 ESP-Hi 机器狗设备
- 扫描完成后，设备列表将显示在界面上

### 2. 连接设备

- 在设备列表中选择要控制的设备
- 点击"连接选中设备"按钮建立连接

### 3. 运动控制

- 使用虚拟摇杆或 WASD 键盘控制机器狗的移动方向
- 虚拟摇杆：鼠标按下并拖动控制方向，释放鼠标发送指令
- WASD 键盘：长按连续发送移动指令

### 4. 执行预设动作

- 在"预设动作"页面，点击对应的动作按钮执行预设动作
- 可以设置循环执行，指定执行间隔时间

### 5. 舵机校准

- 选择一台设备，点击"进入校准模式"
- 使用微调按钮调整各个舵机的角度
- 完成校准后，点击"退出校准模式"

### 6. 动作序列编排

- 在"动作序列"页面，点击"添加动作"按钮
- 选择动作类型（预设动作或移动方向）和延迟时间
- 编排完成后，点击"执行序列"按钮运行整个序列
- 可以设置循环执行整个序列

## 技术细节

### 后端服务

- 服务器运行在 0.0.0.0:5000 端口
- 支持 RESTful API 和 WebSocket 实时通信
- 设备信息保存在 devices.json 文件中

### 前端界面

- 主题切换：支持深色主题和马卡龙浅色主题
- 响应式设计：适配不同屏幕尺寸
- 实时状态提示：各种操作均有相应的成功或失败提示

## 注意事项

1. 确保机器狗设备与控制电脑在同一局域网内
2. 舵机校准模式下，只能对一台设备进行操作，且其他功能将被锁定
3. 若设备意外断电，请使用"应急清理"功能清除校准状态
4. 运动控制时，建议使用适当的指令延迟，避免发送过于频繁的指令
