## 🌟 功能特点

### 📡 设备管理
- **智能扫描**：自动发现局域网内的 ESP-Hi 机器狗设备
- **设备库管理**：集中管理所有已记录的设备
  - 📤 **导出设备**：将设备列表导出为 JSON 文件
  - 📥 **导入设备**：从 JSON 文件批量导入设备
  - 🗑️ **批量删除**：快速删除多个设备
- **灵活连接**：支持单设备或多设备同时连接控制
- **设备重命名**：为设备设置自定义名称，便于识别
- **状态显示**：实时显示设备在线/离线/连接状态
- **显示切换**：可切换查看"已发现设备"或"所有设备"

### 🎮 运动控制
- **虚拟摇杆**：直观的图形化控制界面
  - 鼠标拖动控制方向
  - 鼠标释放发送指令，避免频繁操作
- **键盘控制**：WASD 快捷键控制
  - 长按连续发送移动指令
  - 支持自定义指令下发延迟（100-2000ms）
- **实时反馈**：显示当前移动方向和操作状态

### ⚡ 预设动作
- **12种内置动作**：
  | 动作 | 说明 | 图标 |
  |------|------|------|
  | 趴下 | 机器狗趴下 | 💤 |
  | 鞠躬 | 机器狗鞠躬 | 🙇 |
  | 后仰 | 机器狗后仰 | 🧘 |
  | 摇摆 | 左右摇摆 | 💃 |
  | 前后 | 前后移动 | ↕️ |
  | 左右 | 左右移动 | ↔️ |
  | 握手 | 握手动作 | 🤝 |
  | 戳戳 | 戳戳动作 | 👉 |
  | 抖腿 | 抖腿动作 | 🦵 |
  | 前跳 | 向前跳跃 | 🐇 |
  | 后跳 | 向后跳跃 | 🔙 |
  | 收腿 | 收腿动作 | 📦 |

- **动作循环执行**：
  - 选择任意预设动作进行循环执行
  - 可设置循环延迟时间（0.1-60秒）
  - 一键开始/停止循环

### 🔧 舵机校准
- **单设备校准**：确保校准期间其他功能锁定，避免冲突
- **精准微调**：支持 ±1° 精确调整
  - 前左腿 (FL)
  - 前右腿 (FR)
  - 后左腿 (BL)
  - 后右腿 (BR)
- **实时生效**：调整立即应用到设备
- **应急处理**：提供"强制退出"按钮，设备意外断电时清理状态

### 🎬 动作序列编排
- **丰富指令**：支持 12 种预设动作 + 4 种移动方向
- **灵活编排**：
  - 最多支持 10 个动作的编排
  - 可为每个动作设置延迟时间（0-10秒）
  - 支持删除单个动作或清空全部
- **执行模式**：
  - 单次执行：执行一次编排好的序列
  - 循环执行：设置循环间隔（1-300秒），自动重复执行
- **实时监控**：显示序列执行状态和进度

### 🎨 界面与交互
- **现代化设计**：
  - 🌈 **深色主题**（默认）：专业护眼
  - 🧁 **马卡龙浅色主题**：清新明亮
  - 一键切换主题
- **实时状态**：顶部状态栏显示
  - 服务器连接状态
  - 已记录设备数量
  - 当前连接设备数量
- **友好提示**：所有操作均有成功/失败提示
- **响应式布局**：适配不同屏幕尺寸

### 🔧 技术特性

  - 设备状态实时更新
  - 操作结果即时反馈
  - 扫描进度实时显示
- **RESTful API**：标准的 HTTP 接口设计
- **健康检查**：`/api/health` 端点监控系统状态
- **并发处理**：支持多设备同时操作

## 🚀 快速开始

### 环境要求
- **Python**：3.6 或更高版本
- **操作系统**：Windows / Linux / macOS
- **网络**：控制电脑与 ESP-Hi 设备在同一局域网

### 安装方式

#### 方式一：直接运行可执行文件（推荐）
```bash
# 进入 dist 目录
cd dist

# 直接运行可执行文件
ESP_HI_Control.exe
```

#### 方式二：使用 Python 运行
```bash
# 1. 克隆或下载项目
git clone <repository-url>
cd Web_Cluster_Control_for_ESP_Hi-main

# 2. 安装依赖
pip install -r backend/requirements.txt

# 3. 运行系统
python backend/app.py
```

#### 方式三：使用启动脚本
```bash

run.bat

# 或使用打包脚本

```

### 访问系统
启动成功后，在浏览器中访问：
```
http://localhost:5000
```

## 📖 使用说明

### 1. 设备管理

#### 扫描设备
1. 点击"开始扫描"按钮
2. 系统自动扫描局域网（1-254 IP范围）
3. 扫描完成后显示发现的设备列表

#### 设备库操作
1. **导出设备**：点击"导出设备"按钮，保存为 JSON 文件
2. **导入设备**：点击"从文件导入"按钮，选择 JSON 文件
3. **批量删除**：勾选多个设备，点击"批量删除"按钮

#### 连接设备
1. 在设备列表中选择要控制的设备（支持多选）
2. 点击"连接选中设备"按钮
3. 等待连接完成，成功设备会显示为绿色

#### 设备重命名
1. 在设备库页面找到要重命名的设备
2. 点击设备名称进行编辑
3. 输入新名称并保存

### 2. 运动控制

#### 虚拟摇杆
1. 鼠标按下摇杆中心
2. 拖动到目标方向
3. 释放鼠标发送移动指令

#### 键盘控制
- **W**：前进
- **S**：后退
- **A**：左转
- **D**：右转
- 长按可连续发送指令

#### 设置延迟
在"控制设置"中调整移动延迟时间（100-2000ms），避免指令过于频繁。

### 3. 预设动作

#### 执行动作
1. 在"预设动作"页面选择要执行的设备
2. 点击对应的动作按钮
3. 动作立即执行

#### 动作循环
1. 选择要循环的动作
2. 设置循环延迟时间（0.1-60秒）
3. 点击"开始循环执行"按钮
4. 点击"停止循环"按钮结束

### 4. 舵机校准

#### 进入校准模式
1. 在"舵机校准"页面选择一台设备
2. 点击"进入校准模式"按钮
3. 等待设备进入校准状态

#### 调整舵机
1. 选择要调整的舵机（前左/前右/后左/后右）
2. 使用 + / - 按钮微调角度（±1°）
3. 观察设备姿态变化，实时生效

#### 退出校准
- **正常退出**：点击"退出校准"按钮，保存校准结果
- **强制退出**：点击"⚠️"按钮，不与设备通信直接退出（应急使用）

### 5. 动作序列编排

#### 创建序列
1. 在"动作序列"页面选择设备
2. 从右侧"添加指令"区域选择动作或移动
3. 设置每个动作的延迟时间
4. 点击"添加到序列"按钮
5. 重复步骤 2-4，最多添加 10 个动作

#### 执行序列
- **单次执行**：点击"执行序列"按钮
- **循环执行**：
  1. 设置循环延迟时间（1-300秒）
  2. 点击"开始循环"按钮
  3. 点击"停止循环"按钮结束

#### 编辑序列
- 点击序列中的动作可删除该项
- 点击"清空"按钮可清除整个序列

## ⚠️ 注意事项

1. **网络要求**：确保机器狗设备与控制电脑在同一局域网内
2. **校准限制**：舵机校准模式下，只能对一台设备进行操作，其他功能将被锁定
3. **应急处理**：若设备意外断电，请使用"强制退出"按钮清除校准状态
4. **指令频率**：运动控制时，建议使用适当的指令延迟，避免发送过于频繁的指令
5. **并发限制**：建议同时连接的设备数量不超过 20 台
6. **浏览器兼容**：推荐使用现代浏览器（Chrome、Firefox、Edge）

## 🐛 问题排查

### 常见问题

**Q: 扫描不到设备？**
A: 检查以下几点：
- 设备是否已开机并连接到网络
- 控制电脑和设备是否在同一局域网
- 防火墙是否阻止了扫描端口（端口 80）

**Q: 设备连接失败？**
A: 可能的原因：
- 设备 IP 地址发生变化
- 设备网络连接不稳定
- 设备正在被其他程序控制

**Q: 动作执行无响应？**
A: 检查：
- 设备是否正常连接
- 是否在校准模式下（校准模式下其他操作被锁定）
- 网络延迟是否过高

**Q: 打包失败？**
A: 解决方案：
- 确保 Python 版本 >= 3.6
- 更新 pip：`pip install --upgrade pip`
- 清理缓存：删除 `build` 和 `dist` 目录后重试
