# ESP-Hi 机器狗集群管理系统 V0.0 版本说明文档

## 版本概述

删除 V0.0 文件夹不影响 V1.0 运行，二者完全独立。

本文件夹包含 ESP-Hi 机器狗集群管理系统的 V0.0 版本，这是经过测试后得到的首个可正常达成所有预期目标的版本。本版本提供了包含完整的舵机狗控制功能的 Python 文件，包括设备扫描、多设备控制和舵机校准等核心功能。

## 文件结构

V0.0 版本包含以下主要文件：

| 文件名               | 功能描述               |
| -------------------- | ---------------------- |
| controller.py        | 舵机狗多设备控制程序   |
| scanner.py           | 设备扫描程序           |
| servo_calibration.py | 舵机校准工具           |
| devices.json         | 存储扫描发现的设备列表 |

## 功能详解

### 1. 设备扫描功能 (scanner.py)

**功能概述**：自动扫描局域网内的所有ESP-Hi设备，并将结果保存到devices.json文件中。

**核心特性**：

- 自动获取本机IP地址并生成完整的局域网IP扫描范围
- 使用多线程并行扫描，提高扫描效率
- 支持通过IP地址和主机名("esp-hi.local")两种方式连接设备
- 验证设备响应以确保连接的是正确的ESP-Hi设备

**工作流程**：

1. 获取本机 IP 地址
2. 生成局域网 IP 扫描范围（1-254）
3. 多线程并行扫描每个 IP 地址
4. 验证设备是否响应正确的控制指令
5. 收集并保存有效设备列表到 devices.json 文件

### 2. 多设备控制功能 (controller.py)

**功能概述**：提供对多个舵机狗设备的集中控制，支持预置动作、移动控制和自定义序列等操作。

**核心组件**：

- **ServoDogController**：单设备控制类，负责与单个设备通信并执行命令
- **MultiDeviceManager**：多设备管理类，负责批量控制多个设备
- **_ContinuousTimer**：连续控制定时器，实现长按移动功能

**支持的操作**：

#### 预置动作（12个）

- 1: 趴下
- 2: 鞠躬
- 3: 后仰
- 4: 摇摆
- 5: 前后
- 6: 左右
- 7: 握手
- 8: 戳戳
- 9: 抖腿
- 10: 前跳
- 11: 后跳
- 12: 收腿

#### 移动控制

- F: 前进
- B: 后退
- L: 左转
- R: 右转

**控制模式**：

1. **单次动作执行**：执行单个预置动作或移动命令
2. **连续移动控制**：模拟长按，以固定时间间隔连续发送移动命令
3. **自定义动作序列**：创建包含多个动作和移动的序列，设置每个动作后的延迟时间

**多设备功能**：

- 支持选择单个、多个或全部设备进行批量控制
- 使用线程池实现并发控制，提高多设备操作效率
- 实时显示每个设备的操作结果和状态

### 3. 舵机校准功能 (servo_calibration.py)

**功能概述**：用于校准舵机狗的四肢舵机角度，确保设备动作准确一致。

**校准组件**：

- **CalibrationController**：校准控制器，负责与设备通信并发送校准指令

**支持校准的部位**：

- 前左腿 (fl)
- 前右腿 (fr)
- 后左腿 (bl)
- 后右腿 (br)

**校准流程**：

1. 进入校准模式
2. 调整各个部位的舵机角度（范围：-25 到 25 度）
3. 退出校准模式并保存校准结果

## 使用方法

### 1. 扫描设备

首先需要扫描局域网内的 ESP-Hi 设备：

```bash
python scanner.py
```

扫描完成后，设备列表将保存到 `devices.json`文件中。

### 2. 控制设备

扫描完成后，可以使用控制器程序操作设备：

```bash
python controller.py
```

**基本操作流程**：

1. 选择要控制的设备（支持单个、多个、范围选择或全部选择）
2. 从主菜单选择操作类型：
   - 执行预置动作
   - 单次移动控制
   - 连续移动控制
   - 运行自定义动作序列
   - 重新选择设备

### 3. 校准设备

如果需要校准设备，可以使用校准工具：

```bash
python servo_calibration.py
```

**校准操作流程**：

1. 选择要校准的设备
2. 进入校准模式
3. 选择要校准的部位（前左腿、前右腿、后左腿、后右腿）
4. 调整角度值（-25 到 25 度）
5. 退出校准模式保存结果

## 技术实现细节

### 通信协议

系统通过 HTTP 请求与 ESP-Hi 设备通信，主要使用以下 API：

- 基本控制：`http://{device}:80/control`
  - 执行动作：`{"action": "动作ID"}`
  - 执行移动：`{"move": "方向"}`

校准相关：

- 进入校准模式：`http://{device}/start_calibration` (GET)
- 退出校准模式：`http://{device}/exit_calibration` (GET)
- 调整舵机角度：`http://{device}/adjust` (POST)，参数 `{"servo": "部位", "value": 角度值}`

### 并发控制

系统使用 Python 的 `concurrent.futures.ThreadPoolExecutor`实现并发操作：

- 扫描时使用 100 个线程并行扫描 IP 地址
- 控制多设备时使用 20 个线程并发发送命令
- 连续移动使用定时器线程确保精确的时间间隔

### 错误处理

系统包含完善的错误处理机制：

- 请求超时处理
- 无效命令验证
- 设备连接失败检测
- 用户输入验证和错误提示

## 注意事项

1. 确保设备与控制电脑在同一局域网内
2. 设备扫描可能需要 10-20 秒时间，请耐心等待
3. 连续移动时，建议设置合理的延迟时间，避免命令发送过于频繁
4. 校准操作完成后请记得退出校准模式以保存设置
5. 如果发现设备控制异常，请检查设备连接状态和网络环境，或多测试几次
